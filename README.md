# Forma Studio

A responsive Flutter web dashboard for a small creative studio. It includes a
project overview, weekly focus chart, team activity, project cards, and an
interactive task list with search, filters, completion toggles, and task
creation.

## Run locally

```powershell
flutter pub get
flutter run -d chrome
```

## Build for the web

```powershell
flutter build web
```

The production files are written to `build/web`.
